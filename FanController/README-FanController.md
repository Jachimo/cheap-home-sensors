# FanController

**Work in Progress!**

MicroPython code for making a common HEPA filter (or other device with a multi-
speed fan with separate motor taps) into a 'smart' device that can be controlled
remotely as part of a home automation system.

The inspiration for this project was the relatively high cost and general lack
of options for off-the-shelf 'smart' HEPA filters, and the very low cost and
wide availability of basic 3- or 4-speed filters at my local Goodwill.
