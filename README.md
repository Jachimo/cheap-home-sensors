Cheap Home Sensors
==================

> Inexpensive, self-hostable and DIY-able, remote sensing devices for home
> automation and monitoring.


## TempSensor

MicroPython code and project notes for a basic indoor WiFi+MQTT-connected
temperature and RH measurement unit, using a common ESP8266 board
and one of several sensors: the BME280/BMP280, DHT11/DHT22, DS18B20, or SHT30.

[TempSensor project README file](TempSensor/README-TempSensor.md).


## FanController

MicroPython code to turn a common HEPA air filter with multi-tap motor into a
'smart' device that can be controlled by a home automation system.  Uses some
inexpensive 3V/120V relay modules to control the fan speed.

[FanController project README file](FanController/README-FanController.md)
