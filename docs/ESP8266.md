The ESP8266 "D1 Mini" Module
============================

> Notes on the ESP8266 in the "WeMos D1 Mini" proto board form.

These are just my personal working notes; I think everything here is
correct and I've tried to link to sources where available, but use
with caution!

## Power

Unlike the Raspberry Pi Pico, the D1 Mini doesn't expose separate 5V `VBUS` and
`VSYS` lines -- the `5V` pin is attached to the 5V VCC line on the USB
connector, and the `3V3` pin is driven by the output on the built-in
voltage regulator.

Without extra components, it's probably best to ensure the module only has
one source of 5V power, either from the USB connector *or* an external
source, but not both.

## Pinout

Random Nerd Tutorials has a [nice series of diagrams][rntpins]
showing the pin configuration of various ESP8266 packages and
prototype boards.

[rntpins]: https://randomnerdtutorials.com/esp8266-pinout-reference-gpios/

The "D1 Mini" is a 16-pin proto board with a Micro-USB (or on some later
examples, USB-C) socket, reset switch, and USB/serial chip integrated.

![WeMos D1 Style Module](https://i0.wp.com/randomnerdtutorials.com/wp-content/uploads/2019/05/ESP8266-WeMos-D1-Mini-pinout-gpio-pin.png)

### GPIOs

Not all GPIOs on the board are created equal.  In order to use "deep sleep"
functionality, pin D0 (GPIO 16) must be connected to RESET.   The UART TX
and RX pins occupy GPIO 1 and 3.  GPIO 2 is usually connected to the built-in
SMT LED.

For driving relays, the cleanest GPIO outputs are probably 12, 13, 14
assuming there's no need for SPI. GPIO 15 can also be used, provided it
is not pulled high during the boot process, which will cause the ESP module
to fail to boot.

The I2C pins (GPIO 4 and 5) are also good, assuming I2C isn't needed for
anything.  Many tutorials use these pins preferentially. 

### ADC

Pin A0 (aka ADC0) can only take up to 1V on the actual ESP8266, but most
proto boards implement a voltage divider circuit, making it safe to use 3.3V
as the 100% level. [More information here][rntadc]

[rntadc]: https://randomnerdtutorials.com/esp8266-adc-reading-analog-values-with-nodemcu/

A potentiometer connected to A0 can be used as an alternative to a rotary
encoder for some control applications, freeing up a digital GPIO for other
purposes.
